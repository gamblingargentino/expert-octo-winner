# place/

`HuntOrDie.rbxl` goes here. It is **not** in Git — see the root README.

It is a binary blob and two people editing it cannot merge. Dev A owns it and
shares it out of band when the world changes. Everything mergeable lives in
`src/`.

To create it the first time: open a Baseplate in Studio, delete the baseplate
part, save as `place/HuntOrDie.rbxl`, then `rojo serve` and connect the plugin.
